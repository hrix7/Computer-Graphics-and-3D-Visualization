# Computer Graphics and 3D Visualization

A home for rendering, transformation, lighting, materials, scene-composition, and future biomedical-visualization experiments.

This repository reflects computer-graphics coursework and a completed final scene project. Original course assets will be added only where course and asset licenses permit.

## Included utility

`src/transforms.py` implements homogeneous translation, scale, and axis rotations for learning and testing graphics pipelines.

```bash
python src/transforms.py
```

## Planned structure

- `scenes/`: original scene descriptions
- `renders/`: permission-cleared outputs
- `src/`: graphics utilities
- `docs/`: methods and attribution notes
